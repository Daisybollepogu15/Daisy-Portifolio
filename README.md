## 🌟 Key Features

- **Interactive 3D Quantum Cosmos**: Real-time Three.js WebGL particle sphere and interactive cosmic stars background.
- **Cyber HUD Design**: Futuristic dark-mode aesthetic with neon accents, custom cursor glow, and sleek glassmorphism.
- **Interactive Terminal**: Custom terminal emulator with commands like `help`, `skills`, `projects`, `contact`, `clear`.
- **Project Showcase**: Live demos and repositories for key projects including Quantum Computing algorithms, Smart India Hackathon prototypes, and Full Stack applications.
- **Responsive & Lightweight**: Pure static HTML/CSS/JS without any backend or server requirements.

## 🌐 Deploying to GitHub Pages

To host this portfolio live on GitHub for free:

1. Push or upload this entire repository to your GitHub account.
2. In your repository, go to **Settings** > **Pages** (on the left menu).
3. Under **Branch**, select `main` (or `master`) and leave the folder as `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`!
